# Public Repository Safety

Dieses Repository ist für öffentliche Markt- und Entwicklungsdaten gedacht.

NICHT speichern:
- Scalable-Depotdaten
- Kontostände
- persönliche Orders
- persönliche Dokumente
- Namen/Adressen, sofern nicht ohnehin Teil öffentlicher Emittentendaten
- Passwörter
- Tokens/API-Keys

Der Welt-Swing-Portfolio-State bleibt außerhalb dieses öffentlichen Datenrepositories.
